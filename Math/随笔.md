1、若 a 为素数 且 $a \mid B$ 则 $2B - a = (2k - 1)a$ 为合数，所以 a 作为素数不能为 B 的约数（素因子）

---

> 范围一、以下 a 为素数，且不为B的素因子

2、若 c 与 B 有相同的素因子 p，则 $a = 2B - c = (2k_1 - k_2)p $ 为合数，所以若 a 为素数时，若 c 为合数，则c不能与 B 有 相同的素因子

---

> 范围二、若 c 为合数，则c不能与 B 有 相同的素因子

3、c 若为合数，则素因子不能大于 B 否则 $ c > 2B $

> 范围三、若 c 为合数, 其素因子不能大于 B

---

4、若 a 为 2， 则 $ c = 2B - 2 $ 为合数

> 范围四、a 不为 2

5、若 a 为 c 的素因子，且不等于 2，则 $a + c = a( 1 + k ) = 2B$，则 $a \mid B$，违反范围一

> 范围五、a 不为 c 的素因子

---

总结一、a 为素数，不为 2，不为 B 或 c 的素因子
总结二、若 c 为合数，B、c无相同素因子，c 的素因子不能大于 B
