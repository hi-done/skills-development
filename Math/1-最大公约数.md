使用辗转相除法
```go
package main
import "fmt"
func main() {
    var x, y int = 18, 12 
    result := gcd(x,y)  
    fmt.Printf("x, y 的最大公约数是 : %d",result)
}
func gcd(x,y int) int{
     for y != 0  {     
            x, y = y, x%y 
      }  
    return x
}
```
令 $\gcd (a, b)$ 表示正整数 $a$ 与 $b$ 的最大公约数（$a > b$），则

1. 若 $ a \bmod b = 0$ ，则 $\gcd (a, b) = b$
2. 若 $ a \bmod b = r \neq 0$ ，则 $\gcd (a, b) = \gcd (b, r)$

证明：

令 $r = a \bmod b = a - kb$.

令 $d$ 为 $a$ 与 $b$ 的最大公约数，可记 $a = ud$，$b = vd$，则 $r = a - kb = (u - kv)d$， $\therefore d \mid r$，$\therefore d$ 为 $b$ 与 $r$ 的公约数。

令 $e$ 为 $b$ 与 $r$ 的最大公约数，则 $d \mid e$，可记 $b = xe$，$r = ye$，则 $a = kb + r = kxe + ye = (kx+y)e$

$\therefore e \mid a$，$\therefore e$ 为 $a$ 与 $b$ 的公约数，则 $e \mid d$。

$\therefore d = e$，$\therefore \gcd (a, b) = \gcd (b, r)$
