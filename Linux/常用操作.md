## orphan gopls
```sh
# 查找并清理孤儿 gopls（父进程为 PID 1 的）
ps -eo user:12,pid,ppid,%cpu:5,%mem:5,rss:8,start,cmd:80 \
| awk 'NR==1; /[g]opls/'
# 数字用于显示列的宽度，可自行调整。
```

```bash
ps-gopls() {
    ps -eo user:12,pid,ppid,%cpu:5,%mem:5,rss:8,start,cmd:80 |
    awk '
        NR==1 {header=$0; next}
        /[g]opls/ {print $0 | "sort -k6 -rn"}
        END {print header > "/dev/stderr"}
    '
}
```

| 列名    | 含义                                      | 示例值                                    |
| :------ | :---------------------------------------- | :---------------------------------------- |
| USER    | 进程所属用户                              | `dora`                                    |
| PID     | 进程 ID                                   | `7206` / `7215`                           |
| %CPU    | 最近一段时间占用 CPU 百分比               | `38.1`（表示正在高负载运行）              |
| %MEM    | 占用物理内存占系统总 RAM 的比例           | `8.1%`（占用较高）                        |
| VSZ     | Virtual Memory Size，虚拟内存大小（KB）   | `4191364` ≈ **4.19 GB**（虚拟地址空间）   |
| RSS     | Resident Set Size，实际驻留物理内存（KB） | `827688` ≈ **808 MB**（真实物理内存占用） |
| TTY     | 关联的控制终端                            | `?`（无终端，属于后台/守护进程）          |
| STAT    | 进程状态（多字符）                        | `Sl` / `Ssl`                              |
| START   | 启动时间                                  | `10:43`                                   |
| TIME    | 累计 CPU 时间                             | `1:06`（1分06秒）                         |
| COMMAND | 启动命令行                                | `/home/dora/go/bin/gopls`                 |

STAT 状态码
| 字母  | 含义                                       |
| :---: | ------------------------------------------ |
|  `S`  | Sleeping（可中断睡眠，等事件/IO，正常）    |
|  `R`  | Running / runnable（正在跑或在队列）       |
|  `D`  | 不可中断睡眠（通常等磁盘，少见的卡死信号） |
|  `T`  | 暂停（debugger 或 Ctrl-Z）                 |
|  `Z`  | 僵尸进程                                   |
|  `I`  | 空闲（某些内核线程）                       |

| 标志  | 含义                         |
| :---: | ---------------------------- |
|  `l`  | 多线程（clone 出来的，LWP）  |
|  `s`  | session leader（会话首进程） |
|  `+`  | 前台进程组（在终端里）       |
|  `<`  | 高优先级                     |
|  `N`  | 低优先级                     |

| 状态码 | 解析                                               |
| :----: | -------------------------------------------------- |
|  `Sl`  | 睡眠中 + 多线程（如 gopls 主进程）                 |
| `Ssl`  | 睡眠中 + 多线程 + 会话首进程（如 gopls telemetry） |
|  `R+`  | 运行中 + 前台进程组（终端里正在跑的程序）          |
|  `SN`  | 睡眠中 + 低优先级（Nice 值较高）                   |
