# 登录页面

> 本文档描述系统登录页的 UI 构成与交互流程：页面通过弹窗承载「登录」与「注册」两条业务路径，整体兼容 Web 端与移动端。

## 页面内容

### 登录按钮

| 属性 | 说明 |
| --- | --- |
| 形状 | 圆形 |
| 位置 | 居中偏上 |
| 风格 | 赛车风格启动按钮，具有实物质感 |
| 内容 | Sign in |
| 特效 | 点击时有按压动画 |

### 登录弹窗

| 属性 | 说明 |
| --- | --- |
| 形状 | 卡片 |
| 位置 | 居中 |
| 风格 | 赛博朋克风格 |
| 内容 | 用户名输入框、密码输入框、登录按钮、注册链接文字 |
| 特效 | 不规则闪光 |

### 注册弹窗

| 属性 | 说明 |
| --- | --- |
| 形状 | 卡片 |
| 位置 | 居中 |
| 风格 | 赛博朋克风格，具科技感 |
| 内容 | 用户名输入框、密码输入框、密码重复确认输入框、邀请码输入框、注册按钮 |
| 特效 | 不规则闪光 |

## 业务流程

1. 点击页面上的登录按钮，弹出登录弹窗；
2. 点击登录弹窗中的注册链接文字，关闭登录弹窗，弹出注册弹窗；
3. 点击注册弹窗中的注册按钮，关闭所有弹窗，回到初始状态，仅显示登录按钮。

## 其他

- 兼容 Web 端与移动端。
