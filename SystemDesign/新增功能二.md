# 新增功能二：金价定时采集（huilvbiao.com）

> 本文档记录了「功能二」的完整实现方案与全部代码，可直接复用到其他项目。
> 项目背景：MS 人员管理系统（后端 `ms_back_end`，go-zero + MySQL，手动模式项目）。

## 一、需求

```
新增功能二
https://www.huilvbiao.com/gold
每分钟从以上链接获取金价
存放在数据表gold_price中，如果没有数据表则创建
```

## 二、实现方案

### 2.1 数据源调研结论（关键前提）

直接抓取 `https://www.huilvbiao.com/gold` 的 HTML **拿不到任何金价数值**：页面上三个价格卡片的数值是由 JS 每隔 10 秒请求接口后动态注入的（AJAX），初始 HTML 中对应的 `<span>` 标签是空的。因此采集程序必须直接请求页面背后的数据接口。

**真实数据接口（一次请求即可拿到全部三个品种）：**

```
GET https://www.huilvbiao.com/api/gold_indexApi?t=<毫秒时间戳>
```

返回新浪 hq_str 格式的 JS 变量赋值文本（**不是 JSON**），实际响应样例：

```
var hq_str_gds_AUTD="928.00,0,927.60,927.99,933.16,919.40,15:29:50,933.00,927.01,52108,1.00,3.00,2026-09-15,黄金延期";
var hq_str_hf_GC="4320.576,,4320.600,4320.900,4358.200,4320.300,15:52:15,4351.900,4340.300,0,1,1,2026-09-15,纽约黄金,0";
var hq_str_hf_XAU="4280.11,4298.630,4280.11,4280.46,4317.20,4279.73,15:52:00,4298.63,4301.51,0,0,0,2026-09-15,伦敦金（现货黄金）";
```

**按逗号分割后的字段索引（三个品种格式一致）：**

| 索引 | 含义 | 入库字段 |
|---|---|---|
| [0] | 当前价/最新价 | price |
| [4] | 最高价 | high_price |
| [5] | 最低价 | low_price |
| [6] | 时间 HH:MM:SS | quote_time（与 [12] 拼接） |
| [7] | 昨结算价 | prev_settle |
| [8] | 开盘价 | open_price |
| [12] | 日期 YYYY-MM-DD | quote_time |
| [13] | 品种名称 | （仅参考） |

**品种映射：**

| 接口变量 | symbol | name | unit |
|---|---|---|---|
| hq_str_gds_AUTD | AUTD | 黄金延期（上海黄金交易所） | 元/克 |
| hq_str_hf_GC | GC | 纽约黄金（纽约商品交易所期货） | 美元/盎司 |
| hq_str_hf_XAU | XAU | 伦敦金（伦敦现货黄金） | 美元/盎司 |

**请求注意事项：**
- 需携带 `User-Agent`（浏览器 UA）与 `Referer`（`https://www.huilvbiao.com/gold`）；
- 响应为 UTF-8 中文，`t` 参数传毫秒时间戳用于防缓存（任意唯一值即可）；
- 页面数据每 10 秒刷新一次，本方案采集频率为 1 分钟，足够覆盖。

### 2.2 总体设计

**采集流程：**

1. 后端服务启动时（`ms.go`）开启后台 goroutine：立即采集一次，之后用 `time.Ticker` 每 1 分钟采集一轮；
2. 每轮先从 ServiceContext 取 `GoldPriceModel`（加读写锁，线程安全）；若数据库未连接则跳过本轮，等待下一轮；
3. HTTP 请求数据接口（15 秒超时）→ 正则提取 `hq_str_xxx="..."` → 按字段索引解析出三个品种的记录；
4. 通过事务批量写入 `gold_price` 表；任一环节失败仅记录日志，不影响主服务运行，下一轮自动重试。

**建表时机（满足"如果表不存在则创建"）：**

- 服务启动连接数据库（`tryConnect`）时执行 `CREATE TABLE IF NOT EXISTS gold_price`；
- 在系统配置页保存数据库配置触发重连（`Reconnect`）时同样执行；
- 即：只要数据库连接成功，gold_price 表就一定就绪，无需任何人工操作。

**模块划分：**

| 文件 | 类型 | 职责 |
|---|---|---|
| internal/model/gold_price_model.go | 新增 | 表结构定义与自动建表、批量插入、最近记录查询 |
| internal/task/gold_price_task.go | 新增 | 定时采集任务：HTTP 抓取 + 解析 + 入库 |
| internal/logic/gold_price_logic.go | 新增 | 金价查询业务逻辑 |
| internal/task/gold_price_task_test.go | 新增 | 解析器单元测试 |
| internal/svc/service_context.go | 修改 | 持有 GoldPriceModel；连接/重连时自动建表；线程安全访问器 |
| internal/types/types.go | 修改 | 请求/响应结构体 |
| internal/handler/handlers.go | 修改 | GET /api/gold/list 处理器 |
| internal/handler/routes.go | 修改 | 注册路由 |
| ms.go | 修改 | 启动采集任务 |

**容错设计：**

- 数据库未连接：跳过本轮并记日志，不中断循环；
- HTTP 失败/超时/非 200：记日志，下一轮自动重试；
- 解析时单个品种缺失或价格非法：仅跳过该品种；三个品种全部无效则不写库；
- 响应体读取限制 1MB，防止异常响应占用内存；
- 入库使用事务，一条失败整批回滚，避免半截数据。

### 2.3 数据表结构

```sql
CREATE TABLE IF NOT EXISTS gold_price (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    symbol      VARCHAR(20)  NOT NULL,                          -- 品种代码：AUTD/GC/XAU
    name        VARCHAR(50)  NOT NULL,                          -- 品种名称：黄金延期/纽约黄金/伦敦金
    price       DECIMAL(12,3) NOT NULL,                         -- 当前价
    open_price  DECIMAL(12,3) NULL,                             -- 开盘价
    high_price  DECIMAL(12,3) NULL,                             -- 最高价
    low_price   DECIMAL(12,3) NULL,                             -- 最低价
    prev_settle DECIMAL(12,3) NULL,                             -- 昨结算价
    unit        VARCHAR(20)  NOT NULL DEFAULT '',               -- 计价单位
    quote_time  DATETIME     NULL,                              -- 行情报价时间（数据源）
    created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,-- 入库时间（采集时刻）
    INDEX idx_symbol_created (symbol, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

设计要点：

- 每个品种每分钟一行，`created_at` 附近通常有 3 行（AUTD/GC/XAU 各一）；
- `quote_time` 与 `created_at` 分开：前者是数据源报价时间（国内市场收盘后会停留不变），后者是实际落库时间，两者差值可判断行情新鲜度；
- `DECIMAL(12,3)` 兼容国内价（2 位小数）与国际价（3 位小数）；
- 索引 `(symbol, created_at)` 支撑按「品种+时间」的查询排序。

```go
package model

import (
	"context"
	"database/sql"
	"fmt"
	"time"
)

// GoldPrice represents a row to be inserted into the gold_price table.
type GoldPrice struct {
	Symbol     string
	Name       string
	Price      float64
	OpenPrice  float64
	HighPrice  float64
	LowPrice   float64
	PrevSettle float64
	Unit       string
	QuoteTime  time.Time
}

// GoldPriceRecord represents a row read from the gold_price table.
type GoldPriceRecord struct {
	Id         int64
	Symbol     string
	Name       string
	Price      float64
	OpenPrice  float64
	HighPrice  float64
	LowPrice   float64
	PrevSettle float64
	Unit       string
	QuoteTime  string
	CreatedAt  string
}

// GoldPriceModel handles database operations for gold_price.
type GoldPriceModel struct {
	db *sql.DB
}

// NewGoldPriceModel creates a new GoldPriceModel.
func NewGoldPriceModel(db *sql.DB) *GoldPriceModel {
	return &GoldPriceModel{db: db}
}

// EnsureTable creates the gold_price table if it does not exist.
func (m *GoldPriceModel) EnsureTable(ctx context.Context) error {
	query := `CREATE TABLE IF NOT EXISTS gold_price (
		id BIGINT PRIMARY KEY AUTO_INCREMENT,
		symbol VARCHAR(20) NOT NULL,
		name VARCHAR(50) NOT NULL,
		price DECIMAL(12,3) NOT NULL,
		open_price DECIMAL(12,3) NULL,
		high_price DECIMAL(12,3) NULL,
		low_price DECIMAL(12,3) NULL,
		prev_settle DECIMAL(12,3) NULL,
		unit VARCHAR(20) NOT NULL DEFAULT '',
		quote_time DATETIME NULL,
		created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
		INDEX idx_symbol_created (symbol, created_at)
	) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4`
	_, err := m.db.ExecContext(ctx, query)
	return err
}

// InsertBatch inserts gold price records in a single transaction.
func (m *GoldPriceModel) InsertBatch(ctx context.Context, list []GoldPrice) error {
	if len(list) == 0 {
		return nil
	}

	tx, err := m.db.BeginTx(ctx, nil)
	if err != nil {
		return err
	}

	stmt, err := tx.PrepareContext(ctx, `INSERT INTO gold_price
		(symbol, name, price, open_price, high_price, low_price, prev_settle, unit, quote_time)
		VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`)
	if err != nil {
		tx.Rollback()
		return err
	}
	defer stmt.Close()

	for _, g := range list {
		var quoteTime interface{}
		if !g.QuoteTime.IsZero() {
			quoteTime = g.QuoteTime
		}
		_, err := stmt.ExecContext(ctx,
			g.Symbol, g.Name, g.Price, g.OpenPrice, g.HighPrice,
			g.LowPrice, g.PrevSettle, g.Unit, quoteTime)
		if err != nil {
			tx.Rollback()
			return err
		}
	}

	return tx.Commit()
}

// ListRecent returns the most recent gold price records, optionally filtered by symbol.
func (m *GoldPriceModel) ListRecent(ctx context.Context, symbol string, limit int) ([]GoldPriceRecord, error) {
	query := `SELECT id, symbol, name, price, open_price, high_price, low_price, prev_settle, unit, quote_time, created_at FROM gold_price`
	args := []interface{}{}
	if symbol != "" {
		query += " WHERE symbol = ?"
		args = append(args, symbol)
	}
	query += " ORDER BY id DESC LIMIT ?"
	args = append(args, limit)

	rows, err := m.db.QueryContext(ctx, query, args...)
	if err != nil {
		return nil, err
	}
	defer rows.Close()

	var list []GoldPriceRecord
	for rows.Next() {
		var r GoldPriceRecord
		var openPrice, highPrice, lowPrice, prevSettle sql.NullFloat64
		var quoteTime sql.NullTime
		var createdAt time.Time
		err := rows.Scan(&r.Id, &r.Symbol, &r.Name, &r.Price, &openPrice, &highPrice,
			&lowPrice, &prevSettle, &r.Unit, &quoteTime, &createdAt)
		if err != nil {
			return nil, err
		}
		if openPrice.Valid {
			r.OpenPrice = openPrice.Float64
		}
		if highPrice.Valid {
			r.HighPrice = highPrice.Float64
		}
		if lowPrice.Valid {
			r.LowPrice = lowPrice.Float64
		}
		if prevSettle.Valid {
			r.PrevSettle = prevSettle.Float64
		}
		if quoteTime.Valid {
			r.QuoteTime = quoteTime.Time.Format("2006-01-02 15:04:05")
		}
		r.CreatedAt = createdAt.Format("2006-01-02 15:04:05")
		list = append(list, r)
	}

	if err := rows.Err(); err != nil {
		return nil, err
	}
	return list, nil
}

// CountAll returns the total number of gold price records.
func (m *GoldPriceModel) CountAll(ctx context.Context) (int64, error) {
	var count int64
	err := m.db.QueryRowContext(ctx, "SELECT COUNT(*) FROM gold_price").Scan(&count)
	if err != nil {
		return 0, fmt.Errorf("failed to count gold_price: %w", err)
	}
	return count, nil
}
```

### 3.2 新增：`internal/task/gold_price_task.go`（完整文件，核心采集任务）

```go
package task

import (
	"context"
	"fmt"
	"io"
	"log"
	"net/http"
	"regexp"
	"strconv"
	"strings"
	"time"

	"ms_back_end/internal/model"
	"ms_back_end/internal/svc"
)

const (
	// goldApiURL is the data API behind https://www.huilvbiao.com/gold.
	goldApiURL = "https://www.huilvbiao.com/api/gold_indexApi"
	// goldPageURL is used as the Referer header.
	goldPageURL = "https://www.huilvbiao.com/gold"
	// goldFetchInterval is how often gold prices are fetched.
	goldFetchInterval = time.Minute
	// goldFetchTimeout is the HTTP timeout for a single fetch.
	goldFetchTimeout = 15 * time.Second
)

// goldProducts maps the remote hq_str variable to a stable symbol, display name and unit.
var goldProducts = []struct {
	Var    string
	Symbol string
	Name   string
	Unit   string
}{
	{"hq_str_gds_AUTD", "AUTD", "黄金延期", "元/克"},
	{"hq_str_hf_GC", "GC", "纽约黄金", "美元/盎司"},
	{"hq_str_hf_XAU", "XAU", "伦敦金", "美元/盎司"},
}

// hqStrPattern matches lines like: var hq_str_gds_AUTD="928.00,0,...,黄金延期";
var hqStrPattern = regexp.MustCompile(`var\s+(hq_str_\w+)\s*=\s*"([^"]*)"`)

// StartGoldPriceTask starts a background goroutine that fetches gold prices
// from huilvbiao.com once immediately and then every minute, saving them
// into the gold_price table.
func StartGoldPriceTask(svcCtx *svc.ServiceContext) {
	go func() {
		fetchGoldPrices(svcCtx)

		ticker := time.NewTicker(goldFetchInterval)
		defer ticker.Stop()
		for range ticker.C {
			fetchGoldPrices(svcCtx)
		}
	}()
	log.Printf("[GoldPrice] Collector started, fetching every %s", goldFetchInterval)
}

// fetchGoldPrices fetches the latest gold quotes and stores them in the database.
func fetchGoldPrices(svcCtx *svc.ServiceContext) {
	m := svcCtx.GetGoldPriceModel()
	if m == nil {
		log.Printf("[GoldPrice] Database not connected, skip this round")
		return
	}

	records, err := fetchFromHuilvbiao()
	if err != nil {
		log.Printf("[GoldPrice] Fetch failed: %v", err)
		return
	}

	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	if err := m.InsertBatch(ctx, records); err != nil {
		log.Printf("[GoldPrice] Insert failed: %v", err)
		return
	}

	log.Printf("[GoldPrice] Saved %d records, first quote time: %s",
		len(records), records[0].QuoteTime.Format("2006-01-02 15:04:05"))
}

// fetchFromHuilvbiao downloads and parses the gold quote data.
func fetchFromHuilvbiao() ([]model.GoldPrice, error) {
	url := fmt.Sprintf("%s?t=%d", goldApiURL, time.Now().UnixMilli())
	req, err := http.NewRequest(http.MethodGet, url, nil)
	if err != nil {
		return nil, err
	}
	req.Header.Set("User-Agent", "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36")
	req.Header.Set("Referer", goldPageURL)

	client := &http.Client{Timeout: goldFetchTimeout}
	resp, err := client.Do(req)
	if err != nil {
		return nil, err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("unexpected status: %d", resp.StatusCode)
	}

	body, err := io.ReadAll(io.LimitReader(resp.Body, 1<<20))
	if err != nil {
		return nil, err
	}

	return parseGoldIndex(string(body))
}

// parseGoldIndex parses the sina hq_str style response body into gold price records.
// Field indexes of each quote: [0] current price, [4] high, [5] low, [6] time,
// [7] prev settle, [8] open, [12] date.
func parseGoldIndex(body string) ([]model.GoldPrice, error) {
	quotes := make(map[string]string)
	for _, m := range hqStrPattern.FindAllStringSubmatch(body, -1) {
		quotes[m[1]] = m[2]
	}
	if len(quotes) == 0 {
		return nil, fmt.Errorf("no hq_str data found in response")
	}

	var records []model.GoldPrice
	for _, p := range goldProducts {
		fields := strings.Split(quotes[p.Var], ",")
		if len(fields) < 13 {
			log.Printf("[GoldPrice] Quote for %s missing or malformed, skipped", p.Var)
			continue
		}

		price, err := parsePrice(fields[0])
		if err != nil {
			log.Printf("[GoldPrice] Invalid price for %s: %q", p.Var, fields[0])
			continue
		}

		records = append(records, model.GoldPrice{
			Symbol:     p.Symbol,
			Name:       p.Name,
			Price:      price,
			OpenPrice:  parsePriceOrZero(fields[8]),
			HighPrice:  parsePriceOrZero(fields[4]),
			LowPrice:   parsePriceOrZero(fields[5]),
			PrevSettle: parsePriceOrZero(fields[7]),
			Unit:       p.Unit,
			QuoteTime:  parseQuoteTime(fields[12], fields[6]),
		})
	}
	if len(records) == 0 {
		return nil, fmt.Errorf("no valid gold price parsed")
	}
	return records, nil
}

// parsePrice converts a quote field into a float64.
func parsePrice(s string) (float64, error) {
	return strconv.ParseFloat(strings.TrimSpace(s), 64)
}

// parsePriceOrZero is a lenient variant of parsePrice used for optional fields.
func parsePriceOrZero(s string) float64 {
	v, err := parsePrice(s)
	if err != nil {
		return 0
	}
	return v
}

// parseQuoteTime combines the date and clock fields into a local time.
func parseQuoteTime(date, clock string) time.Time {
	date = strings.TrimSpace(date)
	clock = strings.TrimSpace(clock)
	if date == "" || clock == "" {
		return time.Now()
	}
	t, err := time.ParseInLocation("2006-01-02 15:04:05", date+" "+clock, time.Local)
	if err != nil {
		return time.Now()
	}
	return t
}
```

```go
package logic

import (
	"context"

	"ms_back_end/internal/svc"
	"ms_back_end/internal/types"

// GoldPriceLogic handles gold price queries.
type GoldPriceLogic struct {
	svcCtx *svc.ServiceContext
}

func NewGoldPriceLogic(svcCtx *svc.ServiceContext) *GoldPriceLogic {
	return &GoldPriceLogic{svcCtx: svcCtx}
}

// List returns the most recent gold price records.
func (l *GoldPriceLogic) List(req *types.GoldPriceListReq) (*types.GoldPriceListResp, error) {
	m := l.svcCtx.GetGoldPriceModel()
	if m == nil {
		return &types.GoldPriceListResp{Code: 1, Msg: "数据库未连接，请先配置系统设置"}, nil
	}

	limit := req.Limit
	if limit <= 0 {
		limit = 50
	}
	if limit > 500 {
		limit = 500
	}

	records, err := m.ListRecent(context.Background(), req.Symbol, limit)
	if err != nil {
		return &types.GoldPriceListResp{Code: 1, Msg: "查询失败: " + err.Error()}, nil
	}

	resp := &types.GoldPriceListResp{
		Code: 0,
		Msg:  "success",
	}

	list := make([]types.GoldPriceItem, 0, len(records))
	for _, r := range records {
		list = append(list, types.GoldPriceItem{
			Id:         r.Id,
			Symbol:     r.Symbol,
			Name:       r.Name,
			Price:      r.Price,
			OpenPrice:  r.OpenPrice,
			HighPrice:  r.HighPrice,
			LowPrice:   r.LowPrice,
			PrevSettle: r.PrevSettle,
			Unit:       r.Unit,
			QuoteTime:  r.QuoteTime,
			CreatedAt:  r.CreatedAt,
		})
	}
	resp.Data.List = list

	return resp, nil
}
```

```go
// GetGoldPriceModel returns the current gold price model (thread-safe).
func (sc *ServiceContext) GetGoldPriceModel() *model.GoldPriceModel {
```

## 五、复用要点与注意事项

1. **可调参数**（均在 `gold_price_task.go` 顶部常量与映射表中）：
   - `goldApiURL`：数据接口地址；
   - `goldFetchInterval`：采集间隔（默认 1 分钟）；
   - `goldFetchTimeout`：单次请求超时（默认 15 秒）；
   - `goldProducts`：品种映射表（要增删品种时改这里即可）。
2. **无 CREATE 权限时的兜底**：若数据库账号没有建表权限，先手工执行 2.3 节的 DDL，再启动服务（`CREATE TABLE IF NOT EXISTS` 不会报错）。
3. **非交易时段现象**：国内市场收盘后（约 15:30 起）AUTD 的 `quote_time` 停留在收盘时刻，但每轮仍会写入新行；若需节省存储，可增加「与上一行完全相同时跳过写入」的去重逻辑。
4. **数据量评估**：3 行/分钟 ≈ 4320 行/天 ≈ 13 万行/月，量级很小；长期运行可按 `created_at` 定期归档清理。
5. **页面结构变化风险**：若目标站点改版，只需更新 `goldApiURL` 与字段索引注释（`parseGoldIndex`）；解析失败时任务只记日志不影响主服务，可通过日志 `[GoldPrice] Fetch failed` 快速发现。
6. **复用方式**：把 3.1~3.9 的代码按「新增/修改」标注复制到目标项目即可；目标项目若无 `internal/svc` 机制，只需保证有一个提供 `*sql.DB` 的全局依赖容器（或直接把 `GoldPriceModel` 挂到现有上下文对象上）。
