## 数据库操作

### 创建数据库
```sql
CREATE DATABASE dbname;
```

### 选择数据库
```sh
# 查看数据库列表
\l

# 进入数据库
\c + dbname

# 或者登陆时指定
psql -h localhost -p 5432 -U username dbname
```

### 删除数据库
```sql
DROP DATABASE [ IF EXISTS ] name
```

## 数据表操作
```sh
# 查看表格列表
\d

# 查看表格信息
\d tablename 
```

```sql
-- 删除表格
DROP TABLE table_name;

drop table department, company;
```
