## 数据库操作

### 创建数据库
```sql
CREATE DATABASE dbname;
```

### 选择数据库
```sh
# 查看数据库列表
\l

# 进入数据库
\c + dbname

# 或者登陆时指定
psql -h localhost -p 5432 -U username dbname
```

### 删除数据库
```sql
DROP DATABASE [ IF EXISTS ] name
```

## 数据操作

插入
```sql
INSERT INTO TABLE_NAME (column1, column2, column3,...columnN)
VALUES (value1, value2, value3,...valueN);

INSERT INTO TABLE_NAME VALUES (value1,value2,value3,...valueN);
```

查找
```sql
SELECT column1, column2,...columnN FROM table_name;

SELECT * FROM table_name;
```

更新
```sql
UPDATE table_name
SET column1 = value1, column2 = value2...., columnN = valueN
WHERE [condition];
```

删除
```sql
DELETE FROM table_name WHERE [condition];
```

两种通配符 多个`%` 单个`_`

limit 与 offset
```sql
SELECT column1, column2, columnN 
FROM table_name
LIMIT [no of rows] OFFSET [row num]
```

group by 与 order by
```sql
SELECT column-list
FROM table_name
WHERE [ conditions ]
GROUP BY column1, column2....columnN
ORDER BY column1, column2....columnN
```
GROUP BY 子句必须放在 WHERE 子句中的条件之后，必须放在 ORDER BY 子句之前。

在 GROUP BY 子句中，你可以对一列或者多列进行分组，但是被分组的列必须存在于列清单中。

HAVING 子句可以让我们筛选分组后的各组数据。WHERE 子句在所选列上设置条件，而 HAVING 子句则在由 GROUP BY 子句创建的分组上设置条件。HAVING 子句必须放置于 GROUP BY 子句后面，ORDER BY 子句前面。

## 索引
```sql
-- 单列索引
CREATE INDEX index_name
ON table_name (column_name);

-- 组合索引
CREATE INDEX index_name
ON table_name (column1_name, column2_name);

-- 唯一索引
CREATE UNIQUE INDEX index_name
on table_name (column_name);

-- 局部索引
CREATE INDEX index_name
ON table_name(column_list)
WHERE condition;

-- 删除索引
DROP INDEX index_name;
```
局部索引 是在表的子集上构建的索引；子集由一个条件表达式上定义。索引只包含满足条件的行。

列出数据库中所有索引`\di`

索引不应该使用在较小的表上。
索引不应该使用在有频繁的大批量的更新或插入操作的表上。
索引不应该使用在含有大量的 NULL 值的列上。
索引不应该使用在频繁操作的列上。
